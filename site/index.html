PLATFORM6 TARGETS

WINMACLINUXANDROIDiOSwebOS
FORMATSPMP8000 BIN

游戏加载

解析 SPMP8000 原生 BIN 容器与游戏头，处理 DES 数据，并支持 LZ77/LZSS 与 RLE 解压路径。

CPUARM MODE

ARM 执行

使用 ARM 模式指令解释器运行游戏代码，维护寄存器、内存访问与运行时状态。

GRAPHICS320 × 240

图形输出

支持 RGB565、索引色调色板、透明色与 8 种图像变换，输出常见的 320×240 画面。

AUDIO22050 HZ

音频播放

提供 22050 Hz 立体声混音，覆盖游戏使用的 WAV 解码与 MIDI 合成路径。

RUNTIMESTATE

运行状态

支持重置、版本化即时存档、内容校验、内存与 ARM 寄存器作弊规则。

CONTROLINPUT

输入控制

独立版提供键盘映射，Libretro 版本通过标准手柄接口接收方向键与功能按键。

04 / GET STARTED

使用方式

项目使用 Cargo 构建。准备游戏文件后，可以直接启动独立模拟器；Libretro 核心的构建与安装方式见项目文档。

powershell / bash
# Clone and build
git clone https://github.com/AloysHF/SPMP8000Emu.git
cd SPMP8000Emu
cargo build --release

# Run an SPMP8000 BIN game
cargo run -p spmp8000emu --release -- path/to/game.bin
